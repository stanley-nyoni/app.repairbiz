How License Activation Works

1. Customer's trial expires — they see an "Account Paused" screen asking them to contact you.

2. Customer contacts you via WhatsApp (061 144 0669) or email.

3. They pay you via EFT.

4. Generate a license code here for their plan + duration.

5. Send the code to the customer (WhatsApp, SMS, email).

6. Customer enters the code in their app under Settings → Enter License Code.

7. Account activates immediately — no downtime, no manual intervention.
